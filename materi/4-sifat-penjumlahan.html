4. Sifat-sifat Penjumlahan

Operasi penjumlahan bilangan bulat memiliki 5 sifat penting.

1
Sifat Tertutup

Penjumlahan antara bilangan bulat selalu menghasilkan bilangan bulat juga.

Contoh: 3 + 5 = 8
(8 adalah bilangan bulat)

2
Sifat Komutatif

Urutan bilangan tidak mengubah hasil penjumlahan: a + b = b + a

Contoh: 3 + 5 = 5 + 3 = 8

3
Sifat Asosiatif (Pengelompokan)

Cara mengelompokkan tidak mengubah hasil: (a + b) + c = a + (b + c)

Contoh: (2 + 3) + 4 = 5 + 4 = 9
Sama dengan: 2 + (3 + 4) = 2 + 7 = 9

4
Unsur Identitas

Bilangan 0 adalah identitas penjumlahan. Ditambah 0, hasilnya bilangan itu sendiri: a + 0 = a

Contoh: 7 + 0 = 7

5
Invers Penjumlahan

Setiap bilangan punya lawan (invers). Jika dijumlahkan hasilnya 0: a + (−a) = 0

Contoh: 5 + (−5) = 0
